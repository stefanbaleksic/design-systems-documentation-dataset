    Additional information

    Which entries are listed

    Design systems, UI libraries and style guidelines that are publicly documented. Sources: the awesome-design-systems list on GitHub and web search, collected 17 November 2026.

    Government design systems are a separate type. Case studies are the two systems compared in the thesis.

    How the facts were checked

    • Documentation pages were opened and read. Where a page is rendered by JavaScript or blocks automated access, the entry stays "not checked".
    • Repository licences come from the repository licence file, read through a shallow clone.
    • Release dates come from the latest tag in the repository.

    Reading the values

    • not stated means the source does not say. It is not a claim that none exists.
    • not checked means the entry was not verified yet.
    • Last push is the date of the latest commit on the default branch.

    Limits

    • Inclusion: design systems, component libraries and style guidelines with their own public documentation or repository. Entries with a last commit before 2024 are kept and flagged.
    • Coder agreement has not yet been measured; a pilot on a sample is planned.
    • One collection date. Documentation changes over time.
    • Coding was done by the author. Independent coders check a sample before the dataset is used in the thesis.
    • Some free-text notes may still be in the source language.
