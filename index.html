Design System Documentation Dataset

A dataset of 297 publicly documented design systems, UI libraries and style guidelines. For each entry it records documentation, governance and licence facts as coded by the author, together with repository facts read at source, evidence files and a reproducible build.

What the dataset records

Each entry has a name, a type, a sector, the author's status and verification date, the documentation URL, the repository URL, the licence as coded and as found in the repository licence file, the latest push date, the archive flag, and the package version. It also records whether the design system has a changelog, contributing guide, governance statement, accessibility statement and case study. Sector is the author's classification and is used only for grouping. An empty field means “not checked”, never “no”.

The dataset describes documentation and governance of design systems. It does not describe the components, tokens or platforms of the systems themselves.

Reproduce

git clone https://github.com/stefanbaleksic/design-systems-documentation-dataset.git
cd design-systems-documentation-dataset
python3 -I -m unittest discover -s tests
python3 -I scripts/build_dataset.py
python3 scripts/release.py check
